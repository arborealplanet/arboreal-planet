# Arboreal Planet artwork queue

This checklist is for custom art that will materially improve the public Arboreal Planet site and Arboreal Keeper. Avoid generic stock-looking imagery; use approved Arboreal Planet / Arboreals By Bunn visual language.

## Public site — highest priority

### 1. Green Tree Python reference hero
- Purpose: replace the current text-only reference-structure panel on `/animals/green-tree-python`.
- Recommended format: transparent WebP or PNG, landscape 3:2 to 4:3, at least 1600 px wide.
- Subject: a polished Green Tree Python composition that represents the Arboreal Planet reference identity rather than a generic green snake.
- Keep enough negative space around the animal for responsive cropping.

### 2. Animal Database banner
- Purpose: give `/animals` a strong custom visual anchor without pretending unfinished species pages are complete.
- Recommended format: WebP, 16:9 or 2:1, at least 1800 px wide.
- Suggested subjects: Green Tree Python, Emerald Tree Boa, Boiga, Tree Monitor, and one planted-vivarium/amphibian subject in a unified Arboreal Planet style.

### 3. Plant Database / Nepenthes visual
- Purpose: give `/plants` and the Nepenthes collection a recognizable plant identity.
- Recommended format: transparent WebP/PNG or dark-background WebP, 4:3 or 3:2.
- Subject: custom Nepenthes composition, preferably a real species/approved illustration rather than generic tropical foliage.

### 4. Social share image
- Purpose: OpenGraph / link previews when Arboreal Planet is shared.
- Recommended format: 1200×630 WebP or PNG.
- Include: Arboreal Planet logo, dark brand background, concise tagline, no tiny text.

### 5. Marketplace category icon set
- Purpose: replace generic symbolic category marks as the marketplace fills.
- Matching square icons for: Animals, Plants, Enclosures, Supplies, Feeders.
- Recommended master: 1024×1024 transparent PNG/WebP.

## Public site — secondary

- Learn / Journal header art once published articles exist.
- Events / reptile-show header art once event inventory is populated.
- Optional Community empty-state / welcome art, but user content should remain the visual focus.

## File naming

Use lowercase, hyphenated WebP filenames where possible, for example:
- `/hatchery/snakes/localities/jayapura/red-neonate.webp`
- `/hatchery/snakes/localities/jayapura/adult.webp`
- `/hatchery/snakes/hybrids/pulcher-viridis/red-neonate.webp`

Keep each asset isolated, cleanly cropped, and consistent with the approved Arboreal Keeper sprite style.
