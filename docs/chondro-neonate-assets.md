# Chondro Breeder neonate artwork planning note

## Status

Neonate artwork has **not been approved for production and has not been started**. Do not generate, add, or replace neonate portrait assets unless the project owner explicitly approves that art phase.

The game may still contain life-stage and neonate-color data for gameplay purposes. That does not authorize new artwork.

## Confirmed gameplay rule

Pure `Morelia viridis` hatchlings/neonates are always **Yellow** in Chondro Breeder. A red pure `M. viridis` neonate state is invalid and should be normalized to Yellow.

## Future art rules — only if explicitly approved

- Preserve the correct subspecies identity rather than recoloring one universal snake into all taxa.
- Keep a consistent locked body/pose within each approved subspecies reference set.
- Neonate color is a visual/life-stage state, not a separate genetic trait.
- Pure `Morelia viridis` uses Yellow only.
- Do not create high-expression neonate trait/tier variants unless that separate expansion is explicitly approved.
